# Security Policy

This app runs with administrator rights and talks to hardware through a signed
kernel driver (PawnIO). Security reports are taken seriously.

## Supported versions

Only the latest release gets fixes. Every past version stays downloadable for
rollback, but security fixes always ship as a new release.

## Reporting a vulnerability

Please **don't open a public issue** for a security hole - that hands it to
everyone before a fix exists.

Instead, use GitHub's private reporting: **Security tab → Report a
vulnerability**. The report goes straight to the maintainer, privately.

You'll get a response as fast as a one-person project can manage - typically
within a few days. Fixes ship as a normal release, with honest notes about what
was wrong.
